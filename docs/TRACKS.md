# Track mapping — what to say to each judge

| Track | One-line pitch | Where to point them in the code / demo |
|---|---|---|
| **Anthropic** | Named community: bystanders — the first 4 minutes before EMS arrives, when survival is decided and most people freeze. Claude turns a camera frame into a dispatcher's judgment and keeps a scared person moving, but *only* within vetted protocols. Where it can go wrong: single-frame vision can't see breathing (we ask), false positives (two-frame agreement + one-tap cancel), model outage (Bitdeer → deterministic). | `packages/agent/src/prompts.ts`, `triage.ts`, `coach.ts`; "SCENE" line in the incident log |
| **Cartesia** | Voice *is* the product — hands are on a chest. Sonic over WebSocket with barge-in; Ink STT with client VAD + `finalize` for ~0.5 s turn-taking; scoped browser tokens. README has setup, features used, limitations. | `apps/web/src/lib/voice.ts`, `convex/voice.ts`; flip the "Cartesia / Browser voice" pill to show the difference |
| **Convex** | Entire backend: reactive incidents, actions for vision/voice/fan-out, scheduler for parallel kick-off, HTTP routes for agent webhooks, live helper + ops views with no polling. Zero glue. | `convex/*`; open the helper view on a second phone and watch it update |
| **Factory Droid SDK** | Droid runs on an event we designed (incident close), does real work (report, protocol audit, Jira), with explicit blast radius (sandbox cwd, deny-by-default permissions, secrets only in MCP tools), and its plan/steps/results are shown in-app. | `integrations/droid/src/afterAction.ts`; the "What the agent did" trace in the after-action screen |
| **Fetch.ai** | Open helper-dispatch mesh: dispatch uAgent + responder uAgents speaking a published protocol; acceptances flow back into the victim's voice coach. Third-party agents (campus safety, CERT) can join. | `integrations/fetchai/`; run two responders, watch "Priya (Nurse) is on the way" get spoken |
| **Apify (+ Best Actor)** | Standalone `beacon-aed-finder` actor: OSM + city AED registries → deduped, distance-sorted. Called sync when a cardiac incident opens so the coach can name the AED location. | `integrations/apify-aed-finder/`; the green AED fact chip |
| **Bright Data** | Live public web data is load-bearing in disaster protocols (wildfire/flood/earthquake): NWS alerts + Caltrans closures via Web Unlocker, with explicit handling of blocks/timeouts/empty. Remove it and the coach can't tell you which way is safe. | `convex/lib/brightdata.ts`; the amber "live alert" chip during a wildfire demo |
| **Elastic** | Incident + after-action index; fuzzy search on the ops board for pattern review ("how many cardiac arrests near X had no AED within 300 m"). | `convex/lib/elastic.ts`, `convex/search.ts`; Ops board |
| **Atlassian** | Agentic workforce: the Droid agent files a Jira follow-up per incident with concrete fixes. | after-action screen Jira link |
| **Bitdeer AI Model Studio** | Vendor-independent resilience: identical vision + coaching path through Model Studio's OpenAI-compatible endpoint when Anthropic fails or is slow. | `packages/agent/src/models.ts`; kill the Anthropic key live |
| **Meta — people closer together** | Beacon turns strangers into a response team: nearby trained people are pulled into the incident channel, and the person doing CPR hears that help is 3 minutes out. | helper view + incident log |
| **Microsoft — built for the real world** | Customer understanding (bystander freeze), measurable usefulness (time-to-first-instruction, time-to-911, CPR rate adherence — all logged), prototype→production path (ARCHITECTURE.md), responsible design (README section), end-to-end (camera → voice → alerts → after-action). | README + ARCHITECTURE.md |
| **General: People-First / Most Technically Complex** | Two real-time loops (vision + voice), an AR layer, multi-agent fan-out, graceful degradation at every layer. | — |

Tracks we deliberately did **not** chase: Capital One Nessie, Coinbase x402, CRS, Hyphenate, Visa, SpaceX/Cursor, Mana, SpacetimeDB, Notability, Figma, Moss, Creao, Armadin — bolting them on would weaken the story.
